# Cropmark: screenshot, annotate and redact on Windows 11

Cropmark is a Windows 11 screenshot tool for people who write how-to guides, bug reports and support replies. Capture a region or the full screen, add arrows, boxes, text and numbered step badges, and cover private details with solid redaction before you share.

**Get it:** [Microsoft Store](https://apps.microsoft.com/detail/9NZR4D24CMM6) · **Website:** [tendercrafthq.com/apps/cropmark](https://tendercrafthq.com/apps/cropmark)

## What it does

- Region and full-screen capture
- Arrows, boxes, text and numbered step badges
- Solid redaction that replaces the covered pixels in the exported image
- Export to PNG, JPEG or a single-image PDF, with no watermark on the Free tier
- No account and no upload: files stay on your PC

## Free and Pro

| | Free | Pro (one-time or yearly, via Microsoft Store) |
|---|---|---|
| Capture and annotate | Yes | Yes |
| PNG, JPEG, single-image PDF | Yes | Yes |
| Multi-image projects and multi-page PDF | No | Yes |
| Batch export and saved styles | No | Yes |

## Limits

- Windows 11 (build 22000 or newer), x64 only
- No screen or video recording
- Redaction is manual: you choose each area. Review the exported file before sharing; original captures and editable projects keep the original content.
